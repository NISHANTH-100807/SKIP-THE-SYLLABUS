🚀 Setup Instructions

Windows PowerShell (current session)

$env:XAI_API_KEY = "xai-your-key-here" mvn spring-boot:run

Windows — set permanently (user-level)

[System.Environment]::SetEnvironmentVariable("XAI_API_KEY", "xai-your-key-here", "User") # Then restart your terminal / IDE

PowerShell script (.ps1)

$env:XAI_API_KEY = "xai-your-key-here" $env:XAI_MODEL = "grok-2-1212" # optional Set-Location "path\to\skip-the-syllabus" mvn spring-boot:run

Get your API key at console.x.ai →

The app works in local/demo mode without a key — explanations show document excerpts and quizzes generate fallback questions.

📡 API Endpoints

GET /api/health Health check GET /api/settings AI configuration status GET /api/progress Learning progress stats POST /api/documents/upload Upload PDF (multipart: field=file) GET /api/documents List all documents GET /api/documents/{id} Document metadata GET /api/documents/{id}/content Full text + page sections DELETE /api/documents/{id} Delete document POST /api/documents/{id}/explain AI explanation Body: { "concept": "...", "level": "intermediate" } POST /api/documents/{id}/chat Grounded chat Body: { "message": "...", "history": [{role,content}] } POST /api/documents/{id}/quiz Generate quiz Body: { "questionCount": 5, "difficulty": "mixed" } GET /api/quizzes All quizzes GET /api/quizzes/{id} Quiz with questions POST /api/quizzes/{id}/submit Submit answers Body: { "answers": { "questionId": "A" } } DELETE /api/quizzes/{id} Delete quiz
